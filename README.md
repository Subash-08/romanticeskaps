# romanticeskaps

A high-fidelity, responsive Next.js honeymoon homepage for romanticeskaps, inspired by ORYVIA's editorial travel design language. It includes coordinated entrance, scroll, hover, menu, modal, accordion, route, image, and marquee motion.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm run typecheck
npm run build
```

The planning form is intentionally frontend-only and does not transmit data. Placeholder contact, team, story, and legal content must be replaced before production use.
